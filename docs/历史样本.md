# 本地历史样本

`data/history.json` 是本工具操作格式的合成历史记录，包含 3095 项业务操作；使用全新内存库回放，与演示库相互独立。记录以多周、多主体的变化用于开发自检，不代表真实总体，也不保证任何显著效果或最佳模型。

```bash
python3 -m product replay --file data/history.json
python3 scripts/sample_history.py --output /tmp/local-history.json
```

合成器使用固定随机种子，重复生成应与随附文件相同。其概率只是生成过程参数，不是训练标签或经营规则。部分记录故意不完整或缺少可关联信息，以保留原业务的观察边界；应区分数据缺失和真实零值。不能从样本生成代码推断真实业务规律。

这是一批离线导入的历史事实，数据库变更日志的登记时刻反映本次导入，不证明原业务当时已知的信息；可观察日期与各业务字段的含义见业务约定。分析不能把晚发生的售后、后续活动或更正偷渡到较早判断。原资料未提供的事实应明确作为未知或分析假设，而不是补成确定记录。
